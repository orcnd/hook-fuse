# Hook Fuse

A WordPress plugin that wraps the hook callbacks of plugins the site owner chooses, so an uncaught error in one of them is logged instead of ending the request.

Load the `hook-fuse` skill (`.claude/skills/hook-fuse/SKILL.md`) before any work in this folder: it holds the layout,
the decisions, the design rules and the release steps. The two files below are always loaded.
